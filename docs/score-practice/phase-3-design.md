# 第 3 期设计：复杂乐谱语义与完整练习体验

## 目标

第 3 期处理前两期故意暂缓的复杂问题，让系统更接近真实钢琴练习。

## 主要范围

- 休止、延音线、连音线的正式语义
- 踏板影响下的持续时间处理
- 更稳的左右手归属和交叉手场景
- 回放、复盘和更细的评分解释

## 乐谱语义扩展

### 休止

第 3 期需要把“休止”从隐含空白提升为显式语义，至少在判定层明确：

- 当前是无目标音窗口
- 此时任何非必要按键都构成误按

### 延音线

同音高跨拍或跨小节时，内部建议视为一个连续目标区间，但保留原始乐谱来源信息：

- `tieGroupId`
- `isTieStart`
- `isTieEnd`

这样既能在视觉上显示为一条长目标条，也不会丢掉原始记谱信息。

### 连音线

连音线不是简单的时值相加，而是演奏方式要求。

第 3 期建议：

- 先不强制等于“必须完全重叠”
- 只做“不要断得太明显”的宽松 legato 评价
- 最终结果以提示型反馈为主

## 踏板设计

踏板必须独立建模，不要混在 `ScoreNote` 或 `PerformedNote` 里。

建议对象：

- `PedalSpan`

建议字段：

- `id`
- `sessionId`
- `pedalType`
- `startMs`
- `endMs`
- `startTickEstimate`
- `endTickEstimate`
- `sourceEventIds`

应用原则：

- 手已经松开但踏板仍按下时，声音可视为“声学持续”
- 但是否算作“手指按够了”要单独判断
- 练习视图里最好区分“手指保持”和“踏板延续”

## 左右手高级场景

第 3 期要考虑这些情况：

- 左右手音区交叉
- 同音不同手轮流接力
- 一只手跨到另一谱表区域演奏

因此：

- `hand` 不应完全依赖音高区间推断
- 乐谱中的 `hand` 要继续作为主要依据
- 必要时允许 UI 显示“手别歧义”或“交叉手”

## 回放与复盘

第 3 期建议支持练习复盘：

- 回放目标曲谱时间轴
- 回放实际演奏事件
- 叠加显示错误片段
- 支持按左手 / 右手过滤查看

## 评分思路

第 3 期仍不建议只给总分，应保留可解释评分维度：

- 音高正确率
- 时值覆盖率
- 起始时机偏差
- 连续保持稳定度
- 左右手分别表现
- 误按数量
- 踏板合理性

这样用户才能知道问题具体出在哪一类。
