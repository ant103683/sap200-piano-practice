# 第 3 期任务：复杂乐谱语义与复盘

## 范围

这一期在前两期能跑的基础上，补完整乐谱练习需要的复杂能力。

## 任务拆分

### 1. 扩展乐谱语义

- 正式支持 `tieGroupId`
- 正式支持 `slurGroupId`
- 明确休止区的判定语义
- 记录必要的演奏法标签

### 2. 接入踏板事件

- 从现有 `control_change` 中提取踏板区间
- 建立 `PedalSpan`
- 决定踏板对显示和判定的影响边界

### 3. 优化匹配器

- 处理相邻同音目标切分
- 处理左右手同音/交叉手
- 减少误匹配和双重归属

### 4. 增强反馈解释

- 增加左手 / 右手分别统计
- 增加问题类别统计
- 增加可复盘的错误片段浏览

### 5. 增加回放 / 复盘模式

- 支持按 session 回看
- 支持目标轨和演奏轨叠加
- 支持只看左手、只看右手或双手同看

## 粗略 TODO：高级匹配规则

- 连音线是否需要影响目标结束容差
- 踏板延长是否能弥补手指提前松开
- 左右手交叉时 UI 如何提示而不混乱
- 对连续误按是否需要做去噪策略
- 是否要对 aftertouch / polytouch 做弱支持

## 交付结果

这一期结束时，希望系统具备：

- 可表达较完整的双手曲谱语义
- 可解释的复盘能力
- 对复杂演奏场景不再完全失真
